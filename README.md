# Projeto Prático - Login e Galeria de Fotos

Aplicação web desenvolvida com HTML, CSS e JavaScript. O projeto possui uma tela de login e uma galeria de fotos, com as telas trocadas sem recarregar a página, utilizando o conceito de SPA.

Foram utilizadas duas APIs públicas do JSONPlaceholder:

API de usuários: https://jsonplaceholder.typicode.com/users

API de fotos: https://jsonplaceholder.typicode.com/photos
